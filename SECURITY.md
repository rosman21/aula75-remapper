# Security policy

Remap75 writes settings to a keyboard's memory over USB/HID and runs in the browser (WebHID) and
as a Mac/Linux app. It handles no accounts or network data beyond serving the site.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Use GitHub's private reporting:
[Report a vulnerability](https://github.com/rosman21/aula75-remapper/security/advisories/new).

Include what you found, how to reproduce it, and which build it affects (Mac app, web app,
Linux). This is a hobby project maintained by one person, so expect a reply within about a
week, not hours.

## Supported versions

Only the latest release and the current `main` branch are supported.

## Out of scope

- Problems with the keyboard's own firmware or AULA's software. Contact AULA for those.
- Anything needing physical access to an unlocked machine that's already running the app.
